What works

A model in a tab

WebLLM on WebGPU: SmolLM2, Qwen2.5, Qwen3, Llama 3.2, Gemma 2, Phi-3.5. Real download progress, then it runs on your GPU.

A real local endpoint

Connect Ollama on localhost: list, load and unload models, copy http://localhost:11434/v1 with curl, Python and JS snippets and a Test button.

Pull any model

Type any Ollama tag and watch it download with bytes, percent and cancel.

This machine as a node

Platform, GPU adapter, cores and ready engines, read live from your browser.

Speed on every answer

Tokens per second and time to first token under each reply.

Privacy meter

Network requests since the model loaded. It stays at 0 while you chat in tab mode.

Add a machine

Another computer running Ollama on your network becomes a second node; chats go to whichever you select.

First-run setup

Detects your machine, picks the engine and loads your first model.

Not yet

  • No memory pooling: "add a machine" routes requests, it does not split one model across Macs.
  • No Thunderbolt or RDMA clustering.
  • No native app or menu-bar server. A tab can't open a port, so the in-tab engine has no HTTP endpoint; use Ollama for that.
  • Safari can't reach a local Ollama from an https page; use Chrome or Edge for the Ollama engine.

Run it yourself

git clone https://github.com/VedSoni-dev/berth
cd berth && npm install && npm run dev

For the Ollama engine, allow berth once: OLLAMA_ORIGINS="https://berth-delta.vercel.app" ollama serve. Its page opens with Sign in with publik (the listing goes up the week of 2026-11-19).
